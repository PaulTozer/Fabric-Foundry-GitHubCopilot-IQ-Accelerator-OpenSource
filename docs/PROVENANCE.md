No affected parent contract was overridden and no dependency fork was vendored.
Tailwind 4 handles imports/prefixing itself, so the obsolete Autoprefixer plugin
is removed. Renamed radius/shadow/outline utilities and base defaults are migrated
to retain the existing palette, focus affordances and responsive appearance.
Its browser baseline is Chromium 111+, Safari 16.4+ and Firefox 128+.

The lint migration retains all generic TypeScript/React/hooks/accessibility
rule names from the earlier preset; warning-level checks are enforced as errors
and the modern JSX runtime no longer needs the React-import-use marker. The
Next-specific preset rules are no longer installed. `next build` still runs
ESLint and TypeScript and emits its expected missing-Next-plugin warning; neither
lint nor type checking is bypassed. `npm run lint` retains zero-warning enforcement.
This is a deliberate tooling tradeoff, not an advisory ignore or an assertion
that the unpatched plugin was safe.

The DOCX reader supports transitional/strict WordprocessingML, Unicode UTF-8/16,
paragraphs, tables, hyperlinks, tabs/breaks, legacy symbols and deleted/alternate
markup handling. Existing archive bounds/normalization, sandboxed document
serving, ownership, citations and cleanup remain. DTD/entity definitions,
processing instructions, malformed XML, excessive depth (128) or element count
(200,000), unsupported symbol fonts and embedded alternate documents fail
explicitly. Text output retains the 100,000-character truncation contract while
the rest of the XML is still validated. It never follows document links or
executes embedded content. `saxes` keeps its ISC license and the retained symbol
converter its BSD-2-Clause license; they are not relicensed by root MIT.
